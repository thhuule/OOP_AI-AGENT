## 4. Loi Role A - Systems/Core

### 4.1 Parser khong JSON-unescape string args

Trong `AgentLoop::parse_llm_response()`, parser chi bo hai dau quote ngoai:

```cpp
if (args.size() >= 2 && args.front() == '"' && args.back() == '"') {
    args = args.substr(1, args.size() - 2);
}
```

Parser khong decode cac escape sequence cua JSON. Vi vay command co `\"...\"` co the bi truyen thanh dau quote literal cho shell. Dieu nay xuat hien khi `task_009` co gang xoa cac file bi tao sai ten.

### 4.2 AgentLoop lam mat chi tiet ToolError

AgentLoop dang doi moi loi tool thanh mot chuoi chung:

```cpp
std::string result = res.has_value()
    ? res.value()
    : "Tool Execution Error";
```

Model khong biet loi la `NotFound`, `InvalidArgument` hay `ExecutionFailed`, nen phai doan va retry nhieu lan.

### 4.3 LoopDetector chi so sanh ten tool

LoopDetector luu `act.tool_name`, khong luu kem args. Nam lenh `execute_shell` khac nhau van co the bi coi la mot vong lap.

Dieu nay gop phan lam `task_009` dung voi:

```text
Agent stopped due to infinite loop detection.
```

LoopDetector nen phan biet:

```text
execute_shell + args A
execute_shell + args B
```

thay vi chi so sanh `execute_shell`.

### 4.4 Agent ket thuc task 010 qua som

Yeu cau cua `task_010` gom hai hau dieu kien:

1. `data.txt` co noi dung `initial data`.
2. File co them dong `appended`.

Agent moi tao va doc lai `initial data`, sau do dua final answer. AgentLoop chua co co che nhac model kiem tra toan bo yeu cau truoc khi ket thuc.
