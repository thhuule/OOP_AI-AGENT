# Approved Benchmark Baseline

This is the only benchmark-results directory allowed in Git.

It is intentionally empty until the team approves one clean run. When selecting a baseline, copy the reviewed evidence here and record:

- run ID and Git revision;
- date, provider, and model;
- evaluator score, action-level score, and final success rate;
- whether deterministic fallback could have contributed actions;
- why this run was selected.

Do not commit timestamped `run_*` directories. They remain local evidence by default.
