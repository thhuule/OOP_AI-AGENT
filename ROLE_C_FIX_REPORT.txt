  Ket qua evaluator doc lap, co the van PASS gia.

4. FILE: src/harness/HarnessRunner.cpp
--------------------------------------

4.1. loadTasks()

- Validate top-level JSON array.
- Validate field bat buoc cua moi task.
- Validate eval_type phai co expected_keywords hoac eval_script tuong ung.
- Task requires_tool phai co required_tools.
- Chan task id trung.
- Chan artifact path tuyet doi hoac path co "..".

Ly do:
Task spec sai phai fail ngay luc setup, khong nen chay nua benchmark roi tao
report khong dang tin.

4.2. cleanBenchmarkArtifacts()

- Xoa mot lan truoc khi bat dau ca batch:
  notes.txt, result.txt, capital.txt, output.txt, calc.txt, data.txt.
- Lay them artifact task-specific tu tasks.json.
- Chi cho phep relative path an toan.
- Neu clean that bai, dung batch de tranh artifact cu lam PASS gia.

Ly do:
Clean mot lan truoc batch vua loai file cu, vua giu duoc quan he task_002 tao
notes.txt de task_003 doc trong cung run.

4.3. runSingle()

Luong cham mot task:
1) Reset trajectory.
2) Chay AgentLoop.
3) Chay evaluator va luu raw evaluator score.
4) Kiem tra trajectory co successful tool step lien quan.
5) Tinh final success = evaluator_success && action_level_success.
6) Gan failure_reason.

Failure reason co the xuat:
- PARSER_FAIL
- TOOL_NOT_FOUND
- INVALID_ARGS
- NO_TOOL_EXECUTION
- POST_CONDITION_FAIL
- RATE_LIMIT
- TIMEOUT

Ly do:
Mot functional script co the PASS doc lap, nhung task van phai FAIL neu agent
khong goi tool. Day la cho chan false positive quan trong nhat cua role C.

4.4. createStepHook()

- Van dung Observer/Hook, AgentLoop khong phu thuoc HarnessRunner.
- Moi callback ghi thought, action, tool_result va latency_ms.

Ly do:
Giu dung kien truc de bai va bo sung du du lieu trajectory ma khong tao include
nguoc tu AgentLoop sang harness.

4.5. runAll() va summary

- Hien score theo category simple/medium/hard.
- Hien rieng evaluator_score, action_level_score, final_success_rate.
- Progress dung final success, khong dung raw evaluator success.

4.6. exportResults()

- Moi run tao thu muc timestamp:
  benchmark/results/run_YYYYMMDD_HHMMSS_mmm/
- Khong ghi de ket qua run cu.
- Xuat:
  eval_results.json
  benchmark_summary.txt
  trajectory_task_001.json ... trajectory_task_010.json
- Moi trajectory co task_id, model, success, total_time_ms, failure_reason,
  score va steps.
- Moi step co thought, action, tool_result, latency_ms va tokens_used.

Ly do:
Co the doi chieu nhieu lan chay, khong mat lich su benchmark va khong nham ket
qua cu voi ket qua moi.
